REPOSITORIO PRINCIPAL (Monorepo)
---------------------------------
URL: https://github.com/Fr4nk017/eMeet
Descripción: Monorepo Turborepo con frontend Next.js y todos los microservicios Express.
             Contiene documentación general, configuración de Turbo y paquetes compartidos.
Rama principal: main

ESTRUCTURA DEL REPOSITORIO
----------------------------
El proyecto es un monorepo unificado. Todos los componentes están en el mismo
repositorio organizado por carpetas:

  apps/app-web       → Frontend Next.js 14
  apps/app-auth      → Microservicio de autenticación (:3001)
  apps/app-profile   → Microservicio de perfil (:3002)
  apps/app-events    → Microservicio de eventos (:3003)
  apps/app-saved     → Microservicio de guardados/likes (:3004)
  apps/app-chat      → Microservicio de chat (:3005)
  apps/app-places    → Microservicio de lugares (:3006)
  apps/app-admin     → Microservicio de administración (:3007)
  packages/db        → Esquema Prisma y migraciones
  packages/shared    → Tipos y middleware compartidos
  packages/redis     → Cliente Redis y motor de recomendaciones
